  Injast Admin — راهنمای نصب و اجرا روی ویندوز
═══════════════════════════════════════════════════════════════

■ سیستم‌عامل پشتیبانی‌شده
  • ویندوز ۱۰ (نسخه ۶۴-bit، به‌روزرسانی ۱۸۰۹ یا جدیدتر)  ✓
  • ویندوز ۱۱ (۶۴-bit)  ✓
  • ویندوز ۷ / ۸  ✗  — با Flutter فعلی پشتیبانی نمی‌شود

■ نصب (اولین بار)
  1) کل پوشه را کپی کنید (نه فقط فایل exe).
     باید injast_admin.exe کنار پوشه data و فایل‌های dll باشد.

  2) install_prerequisites.bat را یک‌بار «Run as administrator» اجرا کنید.
     این کار نصب می‌کند:
       - Microsoft Edge WebView2 (برای ورود به سایت اصناف)
       - Visual C++ Redistributable 2015–2022 (x64)

  3) برای اجرا: START_injast_admin.bat یا injast_admin.exe

■ اگر برنامه باز نشد
  • کل پوشه را از حالت Block خارج کنید:
    راست‌کلیک روی پوشه → Properties → تیک «Unblock» → OK
  • آنتی‌ویروس را موقتاً بررسی کنید (فایل exe امضا نشده است)
  • Windows SmartScreen: «More info» → «Run anyway»
  • مطمئن شوید ویندوز 64-bit است (نسخه 32-bit پشتیبانی نمی‌شود)
  • install_prerequisites.bat را دوباره اجرا کنید

■ پوشه data
  حذف یا جابجایی پوشه data باعث خطای اجرا می‌شود.
